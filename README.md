# Cuore del Sud — One-Page Website

A simple, responsive one-page website for **Cuore del Sud**, an Italian export company from Battipaglia.

## Run locally

No build tools are required. Open the HTML file directly:

```bash
open index.html
```

Or double-click `index.html` in your file explorer.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select:
   - **Branch**: `main`
   - **Folder**: `/ (root)`
4. Save. GitHub Pages will publish the site automatically.
